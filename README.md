# Create Clockwork Empire

Official modpack repository for **Create Clockwork Empire** (NeoForge 1.21.1) tailored for Halo Launcher.

## Repository Structure
- `patch_tool/` — Standalone patch utility for existing instances to switch them to GitHub updates.
- `patch_for_friends.zip` — Packaged 1-click patch tool for distribution to players.
- `updates.json` — Modpack version and changelog registry consumed by Halo Launcher.
