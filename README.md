# Create Clockwork Empire

Официальный репозиторий модпака **Create Clockwork Empire** (Minecraft 1.21.1 / NeoForge) для игрового сервера.

## Релизы и Обновления
- `updates.json` — реестр версий и список изменений сборки.
- [GitHub Releases](https://github.com/introllmortal/mindice-modpack/releases) — архивы релизов для автоматической установки и обновлений.
